DEVELOPMENT OVERVIEW

ARCHITECTURE & TECH STACK

Attritable Swarm is built as a lightweight, high-performance web application designed to run instantly inside modern desktop and mobile browsers without external dependencies or heavy frameworks.

  • Core Tech: Vanilla HTML5, CSS3, and modern JavaScript (ES6+).
  • Rendering: Custom HTML5 Canvas rendering loop with procedural battlefield generation, screen shake matrices, particle systems, and canvas-based UI integration.
  • Audio: Fully synthesized audio engine utilizing the browser's Web Audio API (`AudioContext`) — no external audio files or downloads required.
  • Persistence: Local storage implementation with robust fallback handling for private or restricted browser contexts.

DEPLOYMENT & HOSTING

The game source code is hosted on GitHub and deployed directly via custom domain configuration to attritableswarm.org. Continuous updates to the repository update the live environment instantly.

OPTIMIZATION

Engineered with responsive canvas scaling, touch-device adaptors, and high-DPI display adjustments to ensure smooth gameplay across desktop monitors, laptops, tablets, and mobile phones.
