DEVELOPMENT OVERVIEW

ARCHITECTURE & TECH STACK

Attritable Swarm is built as a lightweight web application designed to run instantly inside modern desktop and mobile browsers with no frameworks or libraries.

  • Core Tech: Vanilla HTML5, CSS3, and modern JavaScript (ES6+) in a single page, with no frameworks or game libraries.
  • Rendering: Custom HTML5 Canvas rendering loop with seeded battlefield terrain, screen shake, particle effects, and canvas-based UI integration.
  • Audio: Fully synthesized audio engine utilizing the browser's Web Audio API (AudioContext) — no external audio files or downloads required.
  • Persistence: Local storage implementation with fallback handling for private or restricted browser contexts.
  • Third-party services: Google AdSense (advertising) and Google Analytics (usage statistics). See the Privacy Policy.

DEPLOYMENT & HOSTING

The game source code is hosted on GitHub and deployed directly via custom domain configuration to attritableswarm.org. Continuous updates to the repository update the live environment instantly.

OPTIMIZATION

Engineered with responsive canvas scaling and touch-device controls to support gameplay across desktop monitors, laptops, tablets, and mobile phones.
